# Slang Compilation Pipeline

A composable, multi-stage compilation infrastructure for the Slang programming language with comprehensive error recovery and diagnostic capabilities.

## Overview

The Slang Compilation Pipeline implements a stage-based compilation process where each stage can be individually configured, monitored, and tested. 
The pipeline supports both fail-fast and error recovery modes, making it suitable for both production compilation and development tools.
